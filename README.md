# yumi

Self-hosted meal planner for households: recipes, web recipe import, a "what's next" meal queue, a Bring-style shared shopping list with offline shopping mode, and a tablet-friendly cooking view. Installable as a PWA. UI in German and English.

**Status:** alpha, nothing usable yet. Work is tracked in [issues](https://github.com/reetzjonas/yumi/issues) and [milestones](https://github.com/reetzjonas/yumi/milestones).

Docs: start at [docs/README.md](docs/README.md).
